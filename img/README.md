# 立ち絵の差し替え

このフォルダに画像を置くと、ゲームの仮の立ち絵（`art.js` のSVG）が、自動でその画像に替わります。プログラムを書き換える必要はありません。

- 置いていない表情は、そのキャラの `normal`（ふつう）の画像が使われます。
- `normal` も置いていないキャラは、今までどおり仮の立ち絵のままです。
- なので、1人・1枚ずつ、できたものから置いていけます。

## ファイル名

`キャラID_表情.png` の形で、このフォルダ（`img/`）の直下に置きます。

| キャラ | ふつう | 笑顔 | 照れ | 困り顔 |
|---|---|---|---|---|
| 航 | `wataru_normal.png` | `wataru_smile.png` | `wataru_shy.png` | `wataru_trouble.png` |
| 碧 | `ao_normal.png` | `ao_smile.png` | `ao_shy.png` | `ao_trouble.png` |
| 楓 | `yama1_normal.png` | `yama1_smile.png` | `yama1_shy.png` | `yama1_trouble.png` |
| 暁 | `yama2_normal.png` | `yama2_smile.png` | `yama2_shy.png` | `yama2_trouble.png` |
| 灯 | `machi1_normal.png` | `machi1_smile.png` | `machi1_shy.png` | `machi1_trouble.png` |
| 澄 | `machi2_normal.png` | `machi2_smile.png` | `machi2_shy.png` | `machi2_trouble.png` |

別の名前や場所を使いたいときは、`characters.js` のキャラに `img:{normal:'パス',smile:'パス',…}` を書くと、そちらが優先されます。

## 画像の決まり

- **形式**：PNG、背景は透明
- **大きさ**：横680×縦1200ピクセル（横17：縦30）。同じ比率なら大きさは違っても大丈夫
- **構図**：胸から上（バストアップ）。体の向きは正面か、少し斜め
- **位置**：`_ref/guide.png` の線に合わせる
  - 頭のてっぺん：上から約6%
  - 目の高さ：上から約30%
  - あご：上から約43%
  - 肩：上から約51%
  - 体の中心を、画像の左右の中央に
  - 画像の下の端で、体が切れる（胸のあたり）
- **表情の差分**：4枚とも、顔の位置・大きさ・服・ポーズを同じにして、表情だけ変える。位置がずれると、表情が変わるたびに絵が動いて見えます
- **ファイルの重さ**：1枚500KBくらいまでが目安（スマホで読み込みが遅くならないように）

## キャラごとの見た目

色は今の仮の立ち絵に合わせています。変えてもかまいません（変えたら `characters.js` の `color` も合わせると、名前の札の色がそろいます）。

### 航（わたる）　海・28歳・男性
- **人物**：穏やかで、人に合わせるのが上手すぎる人。散歩と夕焼けの写真が好き
- **見た目**：黒髪で、前髪が少し長めのやわらかい短髪。たれ目ぎみの、やさしい目
- **服**：紺のカーディガンに、白いシャツ
- **表情のポイント**：笑顔は控えめ。照れは目をそらす。困り顔は眉が下がる

### 碧（あおい）　海・30歳・女性
- **人物**：明るくて人懐っこい。古地図集めと食べ歩きが好き。早口
- **見た目**：明るい茶色のボブ。黄色い髪留め。大きく明るい目
- **服**：オレンジ系のコートに、クリーム色のマフラー
- **表情のポイント**：笑顔は大きく。照れは笑ってごまかす感じ

### 楓（かえで）　山・25歳・女性
- **人物**：無口で、言葉より先に手と目が動く。釣りと星空が好き
- **見た目**：深い緑がかった黒髪を、低い位置で一つ結び。肩の前に垂らす。落ち着いた細めの目
- **服**：緑のフリース（ジップアップ、首まで）
- **表情のポイント**：表情の幅は小さく。笑顔もほんの少し口元がゆるむくらい

### 暁（あかつき）　山・35歳・男性
- **人物**：面倒見がよく、頼られることに慣れている。アウトドアの道具の手入れが好き
- **見た目**：茶色の短髪。うっすら無精ひげ。肩幅が広い
- **服**：茶色のアウトドアベストに、赤系のネルシャツ
- **表情のポイント**：笑顔は豪快。照れは頭をかくような気まずさ

### 灯（あかり）　街・27歳・女性
- **人物**：元気で愛想がよく、誰とでもすぐ話せる。食堂を継ぐか迷っている。お菓子作りが好き
- **見た目**：赤みのある茶色の髪をお団子にまとめ、赤いバンダナ。くりっとした明るい目
- **服**：レンガ色のシャツに、生成りのエプロン
- **表情のポイント**：笑顔は満開。困り顔はあわてた感じ

### 澄（すみ）　街・32歳・男性
- **人物**：丁寧で物静か。何でも一人で済ませてきた。純喫茶と文房具が好き
- **見た目**：黒に近い紺の髪を、きちんと分けている。眼鏡。落ち着いた目
- **服**：濃いグレーのタートルネックに、青みのあるコート
- **表情のポイント**：表情は控えめ。照れは眼鏡に手をやる、目をそらす

## 画像生成AIで作るときのコツ

- 6人とも同じ絵柄になるように、同じ指示の書き方・同じ設定で作る
- 1人目の「ふつう」を決めてから、それを元に（参照画像にして）表情を作ると、顔がずれにくい
- 背景が透明にできないときは、単色の背景で作ってから、背景を消すツールで透明にする
- 指示の例（日本語）：「アニメ調の立ち絵、バストアップ、正面、背景なし、28歳の男性、黒髪のやわらかい短髪、たれ目ぎみのやさしい目、紺のカーディガンに白いシャツ、穏やかな表情」

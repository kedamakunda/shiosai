# 潮騒の街で、きみと（仮タイトル）

恋愛ゲームを通して、暮らしの中の防災を間接的に学べるウェブゲームのプロトタイプです。
主人公は街で生まれ育った「近所の人」。お試し住宅に3日間滞在しに来た人を案内しながら、少しずつ距離が縮まっていきます。

- 災害はゲーム中に起こりません。
- 防災は会話の主題にせず、相手の趣味や暮らしの中に自然に出てきます。
- 好感度は「防災の正解」ではなく「相手への関わり方」で変わります。
- エンディングのあとに「この街で身につけた防災メモ」として整理されます。

## 遊び方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

開発用のジャンプ：`index.html#ao` のように `#キャラID` を付けると、そのルートの最初から始まります。
`index.html#ao/ao_d` のようにシーンIDも指定できます。

## キャラクターとルート

| 地域 | キャラ | ファイル |
|---|---|---|
| 海の近く | 航（坂のある海沿い） | `scenario/wataru.js` |
| 海の近く | 碧（平らな埋立地） | `scenario/ao.js` |
| 山の近く | 楓 | `scenario/yama1.js` |
| 山の近く | 暁 | `scenario/yama2.js` |
| 住宅が密集する街 | 灯 | `scenario/machi1.js` |
| 住宅が密集する街 | 澄 | `scenario/machi2.js` |

## ファイル構成

```
index.html          画面の枠と、読み込むファイルの一覧
style.css           見た目（背景・吹き出し・ボタンなど）
characters.js       キャラ設定（名前・色・地域・エンドのしきい値・防災メモ）
version.js          バージョン番号（更新のたびに書き換え、CHANGELOG.md と揃える）
engine.js           進行・分岐・好感度・エンド判定（ふだんは触らなくてOK）
scenario/common.js  共通パート（名前入力 → 街を選ぶ → 地域ごとの導入）
scenario/*.js       各キャラのルート
```

## よくある編集

**セリフを直す**：`scenario/` の該当ファイルを開いて、`L('背景','立ち絵','話す人','セリフ')` の4つ目を書き換えます。`{n}` は主人公の名前に置き換わります。

**キャラの設定を変える**：`characters.js` を編集します。`img:'画像のパス'` を足すと、シルエットが立ち絵画像に替わります。

**新しいルートを足す**：

1. `characters.js` にキャラを追加する（`ready:true` で選択肢に出ます）。
2. `scenario/○○.js` を作る（既存のルートをコピーすると早いです）。
3. `index.html` の末尾に `<script src="scenario/○○.js" charset="utf-8"></script>` を1行足す。

## 一緒に編集するときの約束

- 更新したら `version.js` と `CHANGELOG.md` を書き換えます。
- 大きな変更はブランチを切ってプルリクエストにすると、変更点を確認してから取り込めます。
